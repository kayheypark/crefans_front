# NICE 본인확인·계좌 인증 도입 문의 초안

작성일: 2026-10-23

상태: 문의용 초안. 아직 제출하지 않았으며 계약·요금·업종 취급 승인은 미확인.

나중에 NICE/PASS 또는 창작자 출금 계좌 인증 문의 문구를 요청하면 아래 본문을 기준으로 안내한다. 제출 시 사업 범위·베타 인원·도메인의 변경 여부를 확인한다.

## 신청 항목

- 신청 페이지: [NICE 공식 도입문의](https://b2b.niceid.co.kr/inquiry)
- 도입희망 서비스: **휴대폰본인확인·계좌인증**. 계좌정보확인과 계좌1원인증의 상품 구성은 상담에서 확인한다.
- 적용영역: **회원가입·계좌등록**. 만19세 이상 확인과 창작자 정산 계좌 확인 목적을 문의 본문에 명시한다.
- 연간 예상이용건수·도입시점: 실제 예상치를 입력한다. 초기 베타 인원은 연간 인증 요청 건수와 다르다.
- 문의내용: 아래 블록을 복사한다. 본문은 UTF-8 1,767바이트로 공식 안내의 2,000바이트 제한 이내다.

## 복사용 문의 본문

```text
안녕하세요. 개인사업자 ‘좋아하는일해야지’에서 개발 중인 창작물 공유 플랫폼 ‘크레팬스(CREFANS)’의 휴대폰 본인확인 및 계좌 인증 도입을 문의드립니다.

크리에이터가 사진·영상 등의 창작물을 공유하고, 이용자가 월 멤버십을 구독하는 서비스입니다.

회원가입 단계에서 본인 여부와 생일 기준 만 19세 이상 여부를 확인하려 합니다. PC·모바일 웹에서 PASS 및 문자 인증을 제공하고자 합니다.

창작자 정산용 계좌 등록을 위해 계좌정보확인 및 계좌1원인증 도입도 함께 검토하고 있습니다. 본인확인된 창작자와 계좌 예금주의 일치 여부 및 실제 계좌 점유 여부를 확인하려 합니다. 지원 은행, 검증 가능한 정보, 두 상품의 기능 중복 여부, 최소 월·연 이용료와 건당 비용, 테스트 환경을 함께 안내 부탁드립니다.

현재 소규모 비공개 베타를 준비 중이며, 초기 참여자는 크리에이터 2명과 팬 약 20명입니다.
서비스 도메인: crefans.com
베타 주소: https://beta.crefans.com

아래 사항을 안내 부탁드립니다.
1. 해당 업종의 계약 가능 여부, 심사 기준·필요 서류·소요 기간
2. 가입비·월/연 기본료·최소 약정·건당 요금·부가세 및 실패/취소 건의 과금 기준
3. 소량 이용에 적합한 요금제와 테스트 환경·테스트 키 제공 조건
4. Node.js 서버 연동 문서·샘플 및 도메인·콜백 URL 등록 절차
5. 실명·생년월일·CI/DI 등 제공 항목, 연령 확인에 필요한 최소 정보와 보관·파기 요건

계약 및 테스트 완료 후 베타에 적용할 예정입니다. 감사합니다.
```

## 창작자 출금 계좌 확인 권장안

아래는 도입 검토안이며 공급사 선정·계약이나 실제 연동 완료를 뜻하지 않는다.

| 단계 | 권장 처리 |
| --- | --- |
| 최초 계좌 등록·변경 | 본인확인에서 검증된 정보와 예금주 정보를 대조하고 1원 인증으로 계좌 접근 여부 확인 |
| 출금 신청 | 검증된 계좌 선택 → 금액 확인 → 금액·계좌에 연결된 출금 PIN 인증. 매번 1원 인증을 반복하지 않음 |
| 실제 지급 | 이체 결과를 확인한 뒤 출금 완료 처리. 과거 인증 이후 계좌 폐쇄·정지가 가능하므로 등록 성공을 향후 입금 성공으로 간주하지 않음 |

- [NICE 계좌정보확인](https://niceid.co.kr/prod_acct.nc)은 계좌 유효성과 소유주 정보를 확인한다. [NICE 계좌1원인증](https://www.niceid.co.kr/cpsite/prod_acct2.nc)은 계좌정보 확인에 더해 OTP로 계좌 소지를 확인한다(공식 안내 확인일: 2026-10-23).
- 계약할 1원 인증 상품에 필요한 계좌정보 확인이 포함되는지 확인해 중복 계약·과금을 피한다. 실제 지원 은행·검증 항목·요금은 견적과 기술 자료로 확인한다.
- 현재 [출금 코드](../../crefans_server/src/platform/finance.service.ts)에는 미검증 계좌 차단, 계좌 변경 시 재검증, 금액·계좌·버전에 묶인 출금 인증이 있다. [BankProvider](../../crefans_server/src/platform/bank-provider.ts)는 내부 어댑터만 호출하며, 실제 공급사 연결과 1원 인증 절차는 미구현이다.
- 계좌 확인 서비스와 실제 송금·지급대행은 별도로 준비한다. 이번 문서 저장으로 계약·송금·출금 정책을 변경하지 않는다.

## 근거와 확인 범위

- 2026-10-23 공식 문의 페이지 검색 색인에서 상품·적용영역·2,000바이트 제한을 확인했다. 직접 페이지 읽기에서는 본문 추출이 되지 않아 실 브라우저의 모든 신청 단계나 최신 선택값까지 확인한 것은 아니다.
- 사용자 요청으로 문의 본문의 소개를 ‘창작물 공유 플랫폼’으로 간소화했다. 기존 콘텐츠 운영 정책을 변경한 것은 아니며, 계약 심사에서 콘텐츠 범위를 확인할 경우 실제 운영 계획을 기준으로 설명한다. 이 문의 초안은 NICE의 계약 승인을 의미하지 않는다.
- 현재 본인확인 코드는 [내부 어댑터](../../crefans_server/src/platform/identity-provider.ts)와 [계약 설명](../../crefans_server/docs/provider-contracts.md)을 기준으로 한다. NICE 공식 기술 자료·자격정보 확보 후 공급사 전용 연결 및 실제 인증 검증이 필요하다.
- 후속 준비는 [서드파티 연결 안내](./third-party-setup.md)를 따른다.

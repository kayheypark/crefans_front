## 후속 UI 보완 (2026-09-13)

- 스튜디오 대시보드 지표 아래 순수익·구독자·팔로워 전용 리포트를 추가한다.
- 수익·정산에 출금 간편비밀번호 설정을 연결하고, 출금 요청 확인 후 6자리 검증 단계를 둔다.
- 멤버십은 이미지·항목별 혜택 입력, 공개 노출과 신규 가입을 묶는 활성화 스위치, 유효 구독자가 없을 때 삭제 기능을 제공한다.
- 버전 이력의 보존/향후 공개, PASS, 매일 19:00 미디어 정리는 후속 백엔드 설계로 분리한다. 원문 계층도 자체는 유지하며 상세 경로와 구현 경계는 [화면 검수](./preview-pages.md), [버전 관리](./membership-versioning.md), [출금/PASS](./withdrawal-security-pass.md), [미디어 정리](./media-lifecycle.md)를 확인한다.

## 프롬프트 ① 정사각 168×168 (참고 이미지: crefans-mark-reference.png)

```text
첨부한 이미지는 우리 서비스 '크레팬스(CREFANS)'의 공식 로고 심볼이다. 이 심볼을 새로 디자인하지 말고 모양·비율·색을 그대로 유지해서, 정사각형 앱 아이콘용 로고 이미지 한 장을 만들어줘.

- 캔버스: 1024×1024 정사각형, 배경은 단색 흰색(#FFFFFF). 투명 배경 금지.
- 심볼: 왼쪽 분홍→보라 그라데이션 꽃잎(#FFD0D0 → #F49BDC → #BC79F2), 오른쪽 파랑→보라 그라데이션 꽃잎(#87A8FF → #828BFA → #A47BF4). 두 꽃잎 사이의 흰 틈과 기울기를 첨부 이미지와 똑같이 유지.
- 배치: 심볼을 정중앙에 두고, 심볼이 캔버스 가로·세로의 약 78%를 차지하게 하고 사방 여백을 같게.
- 168×168로 줄여도 형태가 또렷하게 보이도록 가장자리를 깔끔하게.
- 글자, 테두리, 그림자, 3D 효과, 광택, 배경 무늬, 테두리 사각형, 워터마크를 넣지 마. 시안 여러 개가 아니라 한 장만.
```

## 프롬프트 ② 가로형 (참고 이미지: crefans-logo-reference.png)

```text
첨부한 이미지는 우리 서비스 '크레팬스(CREFANS)'의 공식 가로형 로고(심볼 + 'crefans' 글자)다. 로고를 새로 디자인하지 말고 심볼 모양, 글자 모양, 글자 간격, 색, 심볼과 글자의 크기 비율을 그대로 유지해서 가로로 긴 로고 이미지 한 장을 만들어줘.

- 캔버스: 1536×1024 가로형, 배경은 단색 흰색(#FFFFFF). 투명 배경 금지.
- 심볼: 첨부 이미지와 같은 두 꽃잎(분홍→보라 #FFD0D0 → #F49BDC → #BC79F2, 파랑→보라 #87A8FF → #828BFA → #A47BF4).
- 글자: 소문자 'crefans' 한 단어, 진한 남색 #202333, 첨부 이미지와 같은 굵고 둥근 산세리프. 철자를 정확히 c-r-e-f-a-n-s로. 다른 글자나 한글, 슬로건을 추가하지 마.
- 배치: 로고 전체를 캔버스 정중앙에 가로 한 줄로 두고, 로고 전체 폭이 캔버스 폭의 약 84%가 되게. 위아래 여백은 같게.
- 세로 192px로 줄여도 글자가 뭉개지지 않도록 선명하게.
- 그림자, 3D 효과, 광택, 배경 무늬, 테두리, 워터마크를 넣지 마. 시안 여러 개가 아니라 한 장만.
```

## 생성 후 크기 맞추기

- ①: 정사각 이미지를 168×168로 줄인다.
- ②: 로고 위아래 흰 여백을 로고 높이의 약 15%만 남기고 자른 뒤 세로 192px로 줄인다. 가로가 1300px를 넘으면 좌우 여백을 줄인다.
- 결과를 위 "최종 저장 위치"에 넣는다.
